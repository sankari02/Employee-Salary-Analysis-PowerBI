# Employee Annual Salary Analysis Dashboard

## Description
This project is an interactive Power BI dashboard developed to analyze employee annual salary data and provide meaningful business insights through visualizations.

## Features
- Salary Distribution Analysis
- Department-wise Salary Analysis
- Job Role-wise Salary Comparison
- KPI Cards
- Interactive Slicers and Filters
- Data Visualization using Charts

## Tools Used
- Power BI
- DAX
- Microsoft Excel

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

## Project Outcome
The dashboard helps identify salary trends, compare employee salaries across departments, and supports better business decision-making through interactive reports.
